A deterministic paper-trading bot for the pump.fun bonding-curve replay. It watches each mint's recent trade tape, enters maturing curves that show accelerating buy pressure and a healthy real-SOL reserve, manages the whole position with a stop, take-profit, trailing stop and time limit, and fires block-time-paced probe round trips so the distinct-coin guardrail is met. No network, no clock, no randomness: the SDK shim vendored in `vendor/` speaks the replay protocol on stdin/stdout.

## Run it

```sh
node main.ts
```
